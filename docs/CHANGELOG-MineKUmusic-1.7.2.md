# MineKUmusic 1.7.2

同步上游 DangoMusic 1.7.0 更新。

## 新增

- 支持 Minecraft 26.1.2，提供 Fabric / NeoForge 客户端和 Paper / Folia 插件。
- 26.1.2 支持全服点歌、收费确认、投票和 Velocity 切服续播。
- 26.2 / 26.3 支持 Vulkan（3D 歌词会盖在手上）。
- 个人音乐支持歌词翻译：每句歌词下面显示中文翻译（网易云、QQ 音乐、酷狗）。
- 歌词和翻译的颜色可以自由改（设置里的取色器，支持十六进制）。
- 发光可以设成只在晚上开：白天自动关掉，天黑了自动打开。
- 生物跟着节拍跳，可选匀速转圈。BPM 可以自动测，也可以跟着节拍左键点 16 下自己定。
- 性能优化：减少开启歌词时的绘制次数。
- 列表 / 封面墙切换加了滑动动画。

## 修复

- 快捷键不能再绑鼠标左键 / 右键，已经绑了的会自动解除，避免界面无法点击。
- 晚上 Song card、灵动岛、左上角正在播放被原版暗角压暗。
- 和某些模组（如 Placebo）一起用时，其他模组的按键被重置。
- 安卓启动器上中日韩文字不显示。
- 拖音量条后打开设置页闪退。
- 开着 Stay on screen 飞鞘翅时歌词被甩出屏幕。
- 酷狗个人歌单顺序反了。
