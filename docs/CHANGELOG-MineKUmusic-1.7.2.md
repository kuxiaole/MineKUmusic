# MineKUmusic 1.7.2：Minecraft 26.1.2 适配

发布日期：2026-10-30。上游基线为 DangoMusic `6d902b84d6d4b8241d79024723cb0e9e7847c685`（上游 1.7.0）。本次启用已同步的 26.1.2 源码，并接入 MineKU 的全服音乐功能。

## 新增支持

- 新增 **Minecraft 26.1.2 Fabric / NeoForge 客户端**，继续提供 26.2 / 26.3 两种加载器版本。六个客户端 JAR 按游戏版本和加载器分别安装，不能互换。
- 26.1.2 复用现有全服通信与连接管理，支持自愿加入频道、搜索点歌、费用确认、投票、管理员扫码、Velocity 切服和退出后恢复个人播放。
- 补齐 26.1.2 中文输入的启用与释放、MineKU 品牌与作者信息；按该版本的 `Gui` 类验证 HUD 和节拍动画 Mixin 注入点。
- **Paper / Folia 插件最低版本调整为 26.1.2**。发行插件使用 Folia API `26.1.2.build.8-stable` 编译，同一个 JAR 面向 26.1.2 / 26.2 / 26.3。Velocity 插件继续使用 API `4.3.0`。

## 包含此前 1.7.1 更新

- 个人网易云、QQ 音乐、酷狗歌词翻译，歌词与翻译配色、夜间发光和节拍动画。新增翻译仅适用于个人音乐，全服歌词继续使用现有协议。
- HUD 暗角修复、绘制优化、列表切换动画、字体与音量条修复，以及左 / 右鼠标绑定保护。
- 26.1.2 使用 OpenGL；26.2 / 26.3 支持 OpenGL 与 Vulkan 离屏绘制。Vulkan 仍需要驱动支持离屏 OpenGL，3D 歌词会覆盖手部画面。
- 保留 MineKU 全服队列、收费、投票、双音源账号、中文界面与 Java 25 兼容处理。上游 Firebase 房间成员控制未接入全服频道。

## 下载与升级

- 所有组件使用 **Java 25**。26.1.2 Fabric 构建依赖 Fabric Loader `0.19.5`、Fabric API `0.155.3+26.1.2`；NeoForge 构建依赖 `26.1.2.124`。
- 客户端文件：`MineKUmusic-1.7.2+<游戏版本>-<fabric 或 neoforge>.jar`。Fabric 客户端同时需要对应版本的 Fabric API。
- Paper / Folia 插件：`MineKUmusic-server-1.7.2.jar`；Velocity 插件：`MineKUmusic-server-1.7.2-velocity.jar`。不要将服务器插件放入客户端 `mods`。
- **26.1.2 服务器需要更新至 1.7.2 插件**，旧插件的最低 API 声明为 26.2。26.2 / 26.3 上的 1.7.0 / 1.7.1 插件与新版客户端协议兼容。
- 关闭游戏或完整停止服务器后替换 JAR，不要同时保留新旧版本。保留配置、账号 JSON、`queue.json`、`payments.json` 与 `server-id`，此次不更改这些文件格式。
- 完整 ZIP 包含八个 JAR、部署与玩家说明、配置示例、许可证及校验清单；Release 同时提供独立 JAR 与 `SHA256SUMS-v1.7.2.txt`。

## 验证范围

- 八个发行 JAR 在 Java 25 下构建成功；169 项自动化检查通过，无失败、错误或跳过：共享核心 27 项、共享音源 3 项、服务端核心 90 项、Folia 经济适配 7 项、六个客户端目标各 7 项。未修改的共享核心、音源与服务端核心共 120 项复用 Gradle 已有通过结果。
- Folia 的 7 项适配测试分别在 `26.1.2.build.8-stable`、`26.2.build.7-beta`、`26.3.build.5-alpha` API 下通过；重复运行不计入上述总数。最终发行插件由 26.1.2 API 构建。
- 客户端检查覆盖实际数据包编解码、真实游戏字节码中的渲染注入点及 Java 25 兼容规则。已核对八个 JAR 的版本、插件最低 API、全服通信类、Mixin 注册、中文资源、署名与许可证，未包含实际账号和运行状态文件。
- Velocity 完成构建和产物检查，没有独立测试用例。未启动真实游戏或服务器进行联机试听；显卡驱动、光影、实际输入法、扫码和真实经济插件仍需运行环境验证。
