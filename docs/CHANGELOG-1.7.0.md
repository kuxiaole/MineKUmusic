# Dango Music 1.7.0 更新日志

发布日期：2026-10-29。

## 新增

- 支持 Minecraft 26.1.2。
- 26.2 / 26.3 支持 Vulkan（3D 歌词会盖在手上）。
- 歌词翻译：每句歌词下面显示中文翻译（网易云、QQ 音乐、酷狗），翻译的出场动画和 wiggle 可以单独开关。
- 歌词和翻译的颜色可以自由改（设置里的取色器，支持十六进制）。
- 发光可以设成只在晚上开：白天自动关掉，天黑了自动打开。
- 生物跟着节奏跳：世界里所有生物踩着歌曲节拍压扁再拉长，可选匀速转圈。BPM 可以自动测，也可以跟着节拍左键点 16 下自己定（最准）。
- 一起听歌：成员也能切歌、拖进度、暂停，房主可以关掉。自己部署 Firebase 的需要更新数据库规则（见 README）。
- 性能优化：开着歌词时绘制次数减少约八成。
- 列表 / 封面墙切换加了滑动动画。
- 新 logo。

## 修复

- 快捷键不能再绑鼠标左键 / 右键（绑上以后界面里什么都点不了），已经绑了的会自动解除。
- 晚上 Song card、灵动岛、左上角正在播放被原版暗角压暗。
- 和某些模组（如 Placebo）一起用时其他模组的按键被重置（#18）。
- 安卓启动器上中日韩文字不显示。
- 拖音量条后打开设置页闪退。
- 开着 Stay on screen 飞鞘翅时歌词被甩出屏幕。
- 酷狗个人歌单顺序反了。
