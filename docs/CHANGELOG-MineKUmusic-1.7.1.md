# MineKUmusic 1.7.1 上游同步

同步日期：2026-10-30。上游提交：`6d902b84d6d4b8241d79024723cb0e9e7847c685`（DangoMusic 1.7.0）；上次同步基线：`42397a1c8b78138175cfba4781d35cc9ff8aca94`。两个项目独立维护版本号。

## 已接入

- 26.2 / 26.3 的 Vulkan 离屏绘制、HUD 暗角修复、绘制批处理与歌词跟随改进。Vulkan 仍需要驱动支持离屏 OpenGL，3D 歌词会盖在手部画面上。
- 个人网易云、QQ 音乐、酷狗歌词翻译，歌词和翻译取色器、独立翻译动画与抖动、仅夜间发光。
- 生物跟随节拍摇动和转圈、自动 BPM 和手动对拍；默认不开启。
- 列表 / 封面墙切换动画、音量条无效数值处理、左 / 右鼠标按键绑定保护、其他模组按键保留，以及中日韩字体兼容修复。
- 酷狗个人歌单顺序修复和上游新图标。

## MineKU 适配

- 全服页面、服务器队列、Vault 收费确认、切歌投票、管理员扫码、Velocity 切服和个人播放恢复继续沿用 MineKU 实现。上游 Firebase 房间及成员控制不接入全服频道。
- QQ 音源继续复用 `common/sources` 的登录、搜索和播放接口；歌词翻译适配上游数据格式，保留本地音源模型。新增翻译仅适用于个人音乐，全服歌词仍使用既有协议。
- 保留 MineKU 品牌、小乐署名、中文界面、26.2 中文输入生命周期和 Java 25 兼容处理。
- 26.1.2 上游源码保留供参考，不启用对应构建目标，也不宣称该版本的全服音乐兼容。发行目标仍为 26.2 / 26.3 Fabric / NeoForge，以及 Paper / Folia 和 Velocity 插件。

## 升级

1. 关闭游戏，替换对应版本和加载器的客户端 JAR。
2. 1.7.0 服务端插件与 1.7.1 客户端协议兼容；也可使用同包的 1.7.1 插件。替换插件需要完整重启服务器。
3. 保留配置、账号 JSON、`queue.json`、`payments.json` 与 `server-id`。

## 验证结果

Java 25 下六个发行 JAR 构建成功，155 项自动化测试通过，失败、错误和跳过均为 0：共享核心 27 项、共享音源 3 项、服务端核心 90 项、Folia 经济适配 7 项、四个客户端目标各 7 项。Velocity 插件完成构建与产物检查。

自动化检查涵盖共享模块、全服队列与收费流程、四个客户端目标的通信格式及实际游戏字节码中的渲染注入点。新增检查歌词翻译和逐字时间保留、无效音量值、按键迁移、颜色序列化，以及 HUD / 生物动画 Mixin 参数签名。

六个 JAR 均已核对 1.7.1 版本元数据、协议与共享音源类、署名和许可证；客户端另核对新增渲染类、Mixin 注册及中文语言资源。产物不含实际账号或运行状态文件，服务端账号示例为空数组。
