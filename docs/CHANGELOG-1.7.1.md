# Dango Music 1.7.1 更新日志

发布日期：2026-10-30。

## 新增

- 环境音效：水下、室内、洞穴、下雨时歌曲会跟着变化（设置 → 音乐与 HUD → 环境音效）。
- 网易云：每日推荐、私人 FM、红心。
- 酷狗：可以用概念版扫码登录，每天自动领免费会员。
- 音量均衡：不同歌曲音量差不多。
- 网易云原版放不了时自动换其他版本。

## 修复

- QQ 音乐登录三天左右就失效（现在会自动续期，需要重新扫码一次）。
- 1.20.1 / 1.21.1：准星、物品栏和背包背景消失。
- 自己点 BPM 时数字不显示。
- 较新的酷狗账号登录失败（#22），部分酷狗歌曲播放失败。
- 装了 IMBlocker 或在 26.x 上打不出中文（#19）。
- 网易云偶尔连接被重置导致加载失败。
- 安卓：原版文字消失、3D 歌词不显示、没声音或有杂音。
